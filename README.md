## 📌 Overview

**Caption Crafter** is a Python-powered project that utilizes **CNN + Transformer-based architecture** to generate human-like captions for images. Built using **PyTorch**, **TorchVision**, and HuggingFace **Transformers**, it brings together the strengths of computer vision and NLP to solve the challenging task of automatic image captioning.

---

## 🚀 Features

- 📷 Accepts image inputs from file explorer (GUI).
- 🧠 Uses **ResNet-50** for image feature extraction.
- 🗣️ Transformer decoder to generate contextual image captions.
- 🛠️ User-friendly **Streamlit** web interface.
- 🔁 Supports real-time image caption generation.
